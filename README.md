# inayaflow-bots

Small automation bots for InayaFlow, run on free GitHub Actions minutes.

- **Email replier** (`scripts/email_replier/`): reads replies to our link-outreach emails, classifies them with an LLM and sends short, rule-checked replies from our contact address. Public run output contains counts and status codes only.
- **Keepalive**: a monthly commit so GitHub keeps scheduled workflows enabled.

Code only. Credentials live in GitHub Actions secrets. Run logs are stored in a separate private repository, never here.

- **Report robots** (`scripts/reports/`, 19 Nov 2026): `ops-report.yml` (inbox + backlinks report every 3 h, read-only), `backlink-batch.yml` (directory list builder + at most 3 outreach e-mails a day, queued for the outbox robot) and `funnel-daily.yml` (daily counts through one read-only database function). All three are also started by the heartbeat. Results go to the private repository only.
- **Keep-alive check** (`keepalive-check.yml`, `scripts/keepalive/`, 23 Nov 2026): after any robot run and every 20 minutes it starts (workflow_dispatch) any scheduled robot whose newest run is older than 1.5 x its interval (never one already running; max one start per robot per hour). The 3-hourly report shows each robot's last-run age, RED above 2 x its interval.
- **Daily spend caps** (23 Nov 2026, Imran: "Spend 14, maybe $15 a day"; rebalanced 24 Nov): hard daily caps in code, per robot: directory agent $5.10, prospect hunter $4.50, list builder $1.50, platform poster $0.90, backlink batch $1.00, ops-report 160 model calls (about $0.48), email replier 150 calls (about $0.45), mail router 150 calls (about $0.45), DEV poster $0.60. **$14.98 a day is the hard cap of THESE robots only.** The job runner's other jobs have their own, separate $15/day cap (`job-runner.yml`). The test `scripts/keepalive/test_keepalive.py` (WorstCase) adds the caps up from the code.

- **Platform poster** (`platform-poster.yml`, `scripts/platform_poster/`, 24 Nov 2026): one short unique article a day to EACH of WordPress.com, Blogger and Notion (child page of the public page), one plain link each to a rotating inayaflow.ai page (9 tools, hub guides, homepage). Reuses the DEV poster writer/QA/meter. Dry until the repository variable `PLATFORM_POSTER_LIVE` is `true`. State, log and drafts: private repo branch `ops-platform-poster`; new post URLs are listed in the state file under `own_backlinks_new` (for `data/own_backlinks.json`).
- **List builder** (`list-builder.yml`, `scripts/list_builder/`, 24 Nov 2026): once a day (04:23 UTC) Claude Sonnet with web search finds about 150-200 NEW candidate places (AI/SaaS directories, launch sites, tool roundups, awesome lists, review platforms, guest-post and resource pages, communities, podcasts, journalist platforms, edu guides, startup directories by country), rotating 12 categories. Each is de-duplicated by registrable domain against every list we hold, checked live (HTTP 200-399), spam-filtered and added to `data/directories_candidates.json` with `category`, `added` and `source_query` (status `TODO` for directory-type places, `TODO outreach` for outreach-type places, `HOLD paid` for paid-only). Hard cap $1.50 a UTC day (`LIST_BUILDER_DAY_USD_CAP`). State and the daily line "list-builder: +N new (total T; by category ...)" are in `data/list_builder_state.json`. Dry until run with dry_run=false (scheduled runs are live). Signs up nowhere, sends nothing.
- **DEV poster** (`dev-poster.yml`, `scripts/dev_poster/`, 23 Nov 2026): one original article a day to dev.to through the official Forem API (Claude Sonnet writer + Haiku QA, hard cap $0.60 a UTC day over all runs, dry or live). Dry until the repository variable `DEV_POSTER_LIVE` is `true`. State, log and failed drafts go to the private repository only (branch `ops-dev-poster`).
